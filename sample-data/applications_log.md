# Applications

One row per job application. **Only applications live here.** Messages to people (LinkedIn, InMail, recruiter emails)
are in `outreach_log.md`.

> This is invented sample data. Every company, person, address and job id in this folder is made up.

**How to use this file:**
- Before shortlisting or applying, search this file for the **company name** (all sections). Never apply twice to the same company + role.
- New application → add a row at the top of **Waiting for a reply**.
- News about an application → append it to that row's last column ("; 2 Nov: rejected (email)"), then **move the row**
  to the section that matches its new status.
- Something only Sam can do → a bullet in **Needs Sam**; delete the bullet when it's done.
